# SmartCook  
냉장고 속 재료 이미지를 분석하여 해당 재료로 만들 수 있는 요리를 추천하는 웹 서비스입니다.  
스마트 냉장고 없이도 AI 기반 주방 기능을 누구나 사용할 수 있도록 만드는 것을 목표로 개발했습니다.

---

## 1. 프로젝트 개요

1인 가구 증가와 함께 식재료 낭비, 요리 난이도, 재료 관리의 어려움이 지속되고 있습니다.  
SmartCook은 이러한 문제를 해결하기 위해 **이미지 기반 재료 인식 → 레시피 추천** 흐름을 자동화한 서비스입니다.

서비스 핵심 흐름은 다음과 같습니다:

**이미지 업로드 → 재료 인식(YOLO) → JSON 기반 레시피 검색 → 추천 결과 제공**

---

## 2. 개발 목적 / 문제 정의

| 문제 | 설명 |
|------|------|
| 재료 입력의 번거로움 | 기존 레시피 앱은 재료를 직접 입력해야 하는 불편함 존재 |
| 식재료 낭비 | 냉장고 속 재료를 활용하지 못해 폐기되는 비율이 높음 |
| 고가 장비 접근성 문제 | 스마트 냉장고 기능을 일반 사용자도 경험할 수 있는 환경 필요 |

SmartCook은 **한 장의 이미지로 재료를 자동 인식하고 즉시 요리를 추천하여 식재료 활용 효율을 높이는 것**을 목표로 합니다.

---

## 3. 주요 기능

- YOLO 기반 이미지 속 식재료 자동 인식  
- 인식된 재료명으로 JSON 레시피 데이터 검색  
- 추천 레시피의 조리 과정 및 재료 구성 제공  
- 웹 브라우저에서 설치 없이 바로 사용 가능  
- 모바일·PC 환경 모두 지원  

---

## 4. 기술 스택

**Backend:** Python, Django  
**AI Model:** YOLOv8, OpenCV  
**Frontend:** HTML, CSS, JavaScript (Django Template)  
**Data:** JSON 기반 레시피 데이터  
**Tools:** Git, Git LFS, VS Code  

---

## 5. 시스템 구조

<img src="./images/system_flow.png" width="650" />

### 시스템 구성 설명

1. 사용자가 재료 사진 업로드  
2. Django 서버에서 YOLOv8 모델로 이미지 분석  
3. 감지된 재료 목록을 텍스트로 변환  
4. JSON 기반 레시피 데이터에서 관련 레시피 검색  
5. 매칭된 레시피 추천 결과 출력  
6. 최종 결과를 UI로 렌더링하여 사용자에게 제공

## 7. 개인 기여 및 역할

- YOLOv8 기반 재료 인식 모델 적용 및 테스트  
- Django 서버 구조 설계, URL 라우팅 및 API 구현  
- **레시피 추천 알고리즘 설계 및 최적화**  
  - 인식된 재료 조합 기반 가중치 매칭 로직 구현  
  - 다중 재료 매칭 우선순위 계산 알고리즘 개발  
  - 중복 재료·불필요 키워드 제거로 검색 정확도 향상  
- **레시피 데이터 구축 및 정제**  
  - JSON 레시피 데이터셋 직접 수집·구축  
  - 재료명 표준화(소문자 변환, 중복 제거, 띄어쓰기/특수문자 정규화)  
  - 레시피 검색 누락 방지 위한 키워드 확장 및 정제 로직 설계  
- Git LFS 도입 및 대용량 모델 파일 관리 구조 정리  

---

## 8. 기술적 해결 과정

- **YOLO 인식 정확도 개선**  
  - 중복·오인식 문제를 Confidence/IoU threshold 조절 및 데이터 정제로 해결  
- **대용량 모델 파일 관리 문제 해결**  
  - Git LFS 적용으로 안정적 버전 관리  
- **Django Media/Static 충돌 해결**  
  - 업로드 파일 경로 분리 및 URL 매핑 구조 재정립  
- **레시피 매칭 정확도 향상**  
  - 중복 재료 제거, 소문자 변환, 띄어쓰기 정규화 등 데이터 정제 로직 추가  
- **비동기 흐름 최적화**  
  - YOLO 추론과 레시피 검색 순서를 최적화해 응답 시간 감소
