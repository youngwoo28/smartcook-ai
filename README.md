# SmartCook  
냉장고 속 재료를 촬영하면 인식된 재료를 기반으로 레시피를 추천해 주는 간단한 웹 서비스입니다.  
사진 한 장으로 “지금 만들 수 있는 요리”를 바로 찾는 것을 목표로 제작했습니다.

---

## 1. 프로젝트 개요

요리를 자주 하지 않는 사람들은 “뭐 해먹지?”, “재료가 남아서 버리네?” 같은 고민을 자주 겪습니다.  
SmartCook은 이런 문제를 해결하기 위해 **이미지 기반 재료 인식 → 레시피 추천** 흐름을 웹 환경에서 자동으로 처리하도록 구축했습니다.

서비스 흐름은 다음과 같습니다.

**이미지 업로드 → 식재료 인식(YOLO) → 레시피 검색(JSON) → 추천 결과 출력**

---

## 2. 주요 기능

- 업로드한 이미지에서 식재료 자동 인식 (YOLO)
- 인식된 재료명으로 레시피 검색(JSON 기반)
- 추천된 레시피의 조리 과정 확인
- 설치 없이 웹 브라우저에서 바로 사용 가능

---

## 3. 기술 스택

**Backend:** Python, Django  
**AI/Model:** YOLO, OpenCV  
**Frontend:** Django Template (HTML, CSS, JS)  
**Data:** JSON 레시피 데이터  
**Tools:** Git, Git LFS, VS Code

## 6. 개발 의도

- 요리에 익숙하지 않은 사용자도 **재료만 보여주면 요리가 추천되는 경험**을 만드는 것을 목표로 했습니다.
- 스마트 냉장고 없이도 AI 기반 주방 기능을 누구나 이용할 수 있도록 웹으로 구현했습니다.
- 복잡함보다는 **한 장의 사진으로 바로 요리 추천**이라는 단순하고 직관적인 흐름에 집중했습니다.
