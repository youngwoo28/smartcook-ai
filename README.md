# SmartCook  
냉장고 속 재료를 촬영하면 인식된 재료를 기반으로 레시피를 추천해 주는 간단한 웹 서비스입니다.  
사진 한 장으로 “지금 만들 수 있는 요리”를 바로 찾는 것을 목표로 만들었습니다.

---

## 1. 프로젝트 개요

요리를 자주 하지 않는 사람들은 “뭐 해먹지?”, “재료가 남아서 버리네?” 같은 고민이 많습니다.  
스마트 냉장고의 기능을 웹에서 간단하게 구현해보면 좋겠다는 생각으로 시작했습니다.

SmartCook은  
이미지 → 재료 인식 → 레시피 검색 → 추천  
이 흐름을 자동으로 처리하는 형태로 구성되어 있습니다.

---

## 2. 주요 기능

- 업로드한 이미지에서 식재료 자동 인식 (YOLO)
- 인식된 재료명으로 레시피 검색(JSON 기반)
- 추천 레시피에서 조리 과정 확인
- 브라우저에서 바로 사용 가능

---

## 3. 기술 스택

**Backend:** Python, Django  
**AI/Model:** YOLO, OpenCV  
**Frontend:** Django Template (HTML, CSS, JS)  
**Data:** JSON 레시피 데이터  
**Tools:** Git, Git LFS, VS Code
